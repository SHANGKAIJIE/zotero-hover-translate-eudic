## ✨ 功能特性

- **多种取词触发方式**
  - `悬停`：鼠标悬停在单词上，延迟后自动翻译（可配置延迟）。
  - `修饰键 + 悬停`：按住 `Ctrl` / `Alt` / `Shift`（可组合）悬停即翻译；也支持**先悬停再按下修饰键**。
  - `鼠标左键单击`：单击单词即翻译。
- **取词高亮**（v0.3.5 重构）：取词时可以对单词施加高亮。
- **Zotero 10 阅读模式支持**：悬停取词、翻译浮层、取词高亮、`+生词本` / 发音按钮与快捷键在 Zotero 10 阅读模式（Reading Mode / SDT 可重排文档）下同样可用，阅读模式与 PDF 模式之间切换自动生效；隐藏便签图标功能对阅读模式同样生效。
- **复用 Translate for Zotero 引擎**：翻译结果、字典释义、多语种翻译服务直接复用已安装的 Translate 插件。
- **一键同步欧路 / 扇贝 / 墨墨 / 本地 / Zotero 笔记生词本**：翻译弹窗内点击圆形 `+` 按钮，将当前单词加入云端指定生词本、本地 CSV 文件或 Zotero 笔记（添加后切换为 `✓` 或 `✗` 状态反馈）。支持**欧路词典**、**扇贝单词**、**墨墨背单词**、**本地生词本**与**Zotero 笔记**五平台切换。
- **术语库**：划词模式下点击 `+术语库` 按钮，可将术语原文、缩写、释义添加至**本地术语库**与**Zotero 笔记**。
- **加词同步创建 PDF 注释**：添加生词或术语时，可同步在 PDF 上创建高亮/下划线注释，支持翻译写入评论或正文、自动添加标签（v0.2.8）。
- **隐藏便签图标**：按需隐藏 PDF 中高亮/下划线/图片注释的便签图标（支持仅本插件注释 / 全部文本注释两种范围），独立便签图标可单独控制，注释 ID 自动跟踪与清理（v0.2.8）。
- **侧边栏生词本面板**：开启后点击右侧信息栏的本插件图标即可显示生词本面板（仅本地生词表 / Zotero 笔记平台可用）。面板顶部支持「词/语」内容切换（生词本/术语库）、隐藏释义、隐藏音标、放大/缩小字体、排序、清空；单词卡片支持点击跳转原文、编辑与删除，且与本地 CSV / Zotero 笔记**双向同步**（v0.3.1 起；v0.3.2 新增术语库与「词/语」切换）。
- **发音功能**（v0.3.4）：悬停翻译弹窗内新增发音按钮，点击播放当前单词发音；支持取词后自动播放发音、发音快捷键。音源采用**三级发音链**——当前词典源真人发音（跟随 Translate 插件词典源，如必应/有道/海词/剑桥）→ 有道 TTS 合成兜底 → Google TTS 最终兜底，任意来源加载失败自动切换下一级；

## 📦 安装

### 方式一：插件市场安装（推荐）

1. 在 Zotero 中：`工具` → `插件` → 右上角齿轮 → `Install Add-on from Zotero-CN Plugin Market`
2. 搜索 **Hover Translate Eudic**，点击安装。
3. 重启 Zotero。

### 方式二：下载 Release 安装

1. 前往 [Releases](https://github.com/SHANGKAIJIE/zotero-hover-translate-eudic/releases) 页面。
2. 下载最新版本的 `hover-translate-eudic.xpi` 文件。
3. 在 Zotero 中：`工具` → `插件` → 右上角齿轮 → `Install Add-on From File...` → 选择下载的 `.xpi`。
4. 重启 Zotero。

> ⚠️ 若浏览器将 `.xpi` 当作压缩包下载，请右键「链接另存为」并确保后缀为 `.xpi`。

### 方式三：从源码编译

```bash
# 1. 安装依赖
npm install

# 2. 开发构建（含类型检查）
npm run build

# 3.（可选）启动热重载开发服务器
npm start
```

构建产物位于 `.scaffold/build/`，其中的 `zotero-hover-translate-eudic.xpi` 即为可安装的插件包。

## ⚙️ 配置说明

打开 Zotero：`编辑` → `首选项` → `Hover Translate Eudic`（或在 macOS 上为 `Zotero` → `设置` → `Hover Translate Eudic`）。

设置面板顶部为**横向标题页签**，点击切换，共六个页签：

`基础` / `生词本` / `术语库` / `侧边栏` / `注释` / `导出`

### 基础功能设置

**启用高亮**：勾选后，鼠标取词时对单词施加**临时**高亮标记（仅视觉提示，不修改 PDF 文件内容）。

**高亮颜色**：通过颜色选择器拾取颜色，或直接在 `Color` 输入框中填写十六进制颜色值（格式 `#ffd400`），并在「透明度」中调整不透明度（0–100%，默认 100%）。默认高亮颜色为 `#ffe94f`。

**启用悬停翻译(插件总开关)**：控制插件的取词翻译功能是否启用。取消勾选后，取词触发方式 / 悬停延迟 / 弹窗关闭 / 显示模式均变为灰色不可操作。

**取词触发方式**：在三种触发方式中选择一种：

| 模式 | 说明 |
| --- | --- |
| 悬停 | 鼠标悬停到单词上触发，延迟可在「悬停触发延迟」中设置。 |
| 修饰键 + 悬停 | 选中下方修饰键（Ctrl/Alt/Shift 可组合），悬停即翻译；支持先悬停后按修饰键。 |
| 鼠标左键单击 | 单击单词即翻译，悬停延迟设置在此模式下禁用。 |

**悬停触发延迟**：设置悬停触发翻译的延迟时间（单位：毫秒，默认 900ms）。插件内置两级预热机制——鼠标停 200ms 即开始后台翻译缓存，弹窗打开时翻译结果已就绪。点击模式下 mousedown 也会即时预热，缩短点击翻译等待时间。

**弹窗位置**：选择翻译弹窗相对单词原文的位置——`单词上方`（默认）或 `单词下方`，弹窗紧贴文本（8px 间距），左边缘与单词左边缘对齐；空间不足时自动翻转到另一侧，越界时收进视口。**完整模式布局跟随弹窗方向**：字典释义区始终位于远离单词的一侧（弹窗在上方时释义在弹窗上部、在下方时释义在弹窗下部），单词/译文/+按钮 核心区永远贴近单词，分割线始终位于释义与核心区之间。

**弹窗自动关闭**：设置翻译弹窗自动关闭的延时（单位：秒，默认 30 秒），设为 0 则不自动关闭。

**译文引擎**：选择翻译所使用的引擎，行为与 pdf-translate 设置面板的「使用字典服务翻译词语」语义一致：
| 引擎 | 说明 |
| --- | --- |
| 字典引擎（更快，取首条释义） | 单词优先调用词典源（如必应词典，免费且稳定），失败自动回退翻译源；短语/非单词仍走翻译源。 |
| 翻译引擎（稍慢，释义更贴切） | 一律直接调用翻译源，不经过词典源，返回最贴合上下文的译文。 |

> 若翻译结果 **[请求错误]**，可去 Translate 插件切换翻译引擎。

> 字典引擎的「首条释义」提取已适配 Translate 插件全部词典源。可在Translate插件设置面板的字典服务切换不同字典。

**翻译显示模式**：控制翻译弹窗中的内容：
| 模式 | 说明 |
| --- | --- |
| 简单翻译 | 仅显示一个译文结果，快速看懂。 |
| 完整释义 | 翻译结果外附加字典释义，深挖词义。 |

**划词时禁用悬停弹窗（避免与划词翻译弹窗冲突）**：勾选后（默认勾选），抑制悬停翻译弹窗，避免与 Translate for Zotero 的划词翻译弹窗重叠冲突。具体行为：

**悬停弹窗中显示发音按钮**：勾选后，悬停翻译弹窗内显示圆形发音按钮（🔊），点击播放当前取词单词的发音。

**发音快捷键**：设置全局快捷键，翻译弹窗出现时按快捷键即可播放当前单词发音（等效点击发音按钮）。录制方式与加词快捷键一致——点击输入框后直接按下按键（支持单键或 `Ctrl`/`Alt`/`Shift`/`Meta` 组合），`Backspace` 清空（= 不启用），`Escape` 取消。**与加词快捷键互斥**：任一方设置为另一方相同的按键组合时，会弹出提醒并拒绝保存。留空则不启用快捷键。

**取词后自动播放发音（不启用发音按钮也自动发音）**：勾选后，取词翻译弹窗加载完成即自动播放单词发音；不依赖上方发音按钮开关。

> **发音音源（三级链）**：① 当前词典源（Translate 插件的「词典源」设置，如必应/有道/海词/剑桥等）返回的真人发音 → ② 有道 TTS 合成（国内可达）→ ③ Google TTS 合成（最终兜底）。播放时按顺序尝试，前一来源加载失败自动切换下一级；生词本面板的发音按钮同样走 ② → ③ 链路。词典查不到词条的生僻词/变形词自动走 TTS，无需配置。

### 生词本设置

**启用生词本同步**：本板块总开关，勾选后翻译弹窗与划词按钮中才会显示 `+`（生词本）按钮，下方所有生词本选项变为可操作。

**生词本平台**：选择同步目标平台 — **欧路词典**、**扇贝单词**、**墨墨背单词**、**本地生词本** 或 **Zotero 笔记**。

#### 欧路词典

插件通过欧路 OpenAPI 同步生词本，需要一个 **NIS Token**：
1. 登录[欧路 OpenAPI 获取授权](https://my.eudic.net/OpenAPI/Authorization)。
2. 在插件设置中填入 Token（格式为 `NIS <你的token>`，支持带或不带前缀）。
3. 点击「刷新列表」拉取你的生词本。

#### 墨墨背单词

插件通过墨墨开放 API 同步云词本，需要一个 **Access Token**，有两种方式获取与维护：

**方式一：手动获取（无需浏览器插件）**
1. 登录[墨墨开放平台](https://open.maimemo.com/open/api/v1/tokens/openapi)，申请 Access Token。
2. 复制 Token 粘贴到插件设置面板。
3. Token 有效期 24 小时，过期后需重新获取。

**方式二：自动续期（推荐，需 HTE Bridge）**
1. 安装 [HTE Bridge](https://github.com/SHANGKAIJIE/hte-bridge) 浏览器扩展，加载后自动检测墨墨登录状态。
2. 确保已在浏览器中登录[墨墨开放平台](https://open.maimemo.com/open/api/v1/tokens/openapi)。
3. 打开 HTE Bridge 弹出面板，确认墨墨显示已登录。
4. 点击「刷新同步」推送 Token，之后每 23h 自动续期，无需手动操作。

> ⚠️ Token 仅 24 小时有效，建议配合 HTE Bridge 自动续期，避免手动重复获取。

#### 扇贝单词

插件通过 Zotero 内置 HTTP 服务器接收浏览器扩展推送的 Auth Token，实现无感同步：

1. **安装 [HTE Bridge](https://github.com/SHANGKAIJIE/hte-bridge) 浏览器扩展**，加载后自动读取扇贝登录 Cookie 并推送到 Zotero。
2. 确保已在浏览器中登录[扇贝网页版](https://web.shanbay.com/wordsweb/#/collection)。
3. 打开 HTE Bridge 弹出面板，确认 Zotero 已连接、扇贝已登录，点击「刷新同步」推送 Token。
4. Token 自动填入插件设置面板，无需手动复制粘贴。

> 扇贝单词的 API 自动将变形词归一化为词典原型，添加到生词本时始终以原型存储。

> 参考实现：[扇贝单词助手 V3](https://github.com/honwhy/shanbay-ext) — 扇贝查词 / 添加生词浏览器扩展。

#### 本地生词表

插件将生词直接保存到本地 CSV 文件，无需API配置：

1. 选择 **本地生词本**，设置 **存储路径**（留空则保存在 Zotero 配置目录）。
2. 点击 `+` 按钮后，单词及其音标、释义自动写入 CSV 文件。
3. CSV 格式为 UTF-8 BOM（Excel 兼容），列：`word, phon, exp, add_time, status, tries, src`（src 为原文跳转链接，供生词本面板点击跳转使用；旧 4/6 列文件自动兼容）。
4. phon 和 exp 内容来自 zotero-pdf-translate 的字典引擎结果。

> 通过 **导出生词本** 功能可将 CSV 导出为其他格式。

#### Zotero 笔记

插件将生词保存为 Zotero 中的一条笔记（默认标题「生词本」，带 `hover-translate-eudic-wordbook` 标签），无需任何 Token ：

1. 选择 **Zotero 笔记**，笔记名称固定为「生词本」，点击「打开笔记」可直接在 Zotero 中打开并编辑该笔记。
2. 点击 `+` 按钮后，单词及其音标、释义以结构化 HTML 追加写入笔记，每个词条含原文、音标、释义与 PDF 出处链接（可点击跳回原文位置）。
3. 在生词本面板中编辑 / 删除词条会同步修改该笔记内容。

**选择生词本**：从拉取的生词本列表中选择目标词本，翻译弹窗点击 `+` 按钮时加入该词本（Zotero 笔记平台下固定为「生词本」，无需选择）。


**词形选择**：控制添加到生词本时是否进行词形还原——

| 选项 | 说明 |
| --- | --- |
| 还原为单词原型 | 调用词形还原引擎（BNC 词典 + 不规则表 + 后缀规则），将变形词转为原型后上传 |
| 保留变形词（复数 / 过去式 等）| 直接以上下文中的词形上传，不进行词形还原 |

> 建议选择「单词原型」，变形词加入生词本可能导致缺少音标和释义。此选项对欧路词典、本地生词本与 Zotero 笔记均生效；墨墨背单词（App 展示层已自动归一化为词典原型）与扇贝单词（API 自动归一化）平台下该选项不显示。

**单词语言**：设置加入生词本的单词语言（en/fr/de/es 等）。

**同步至本地**（仅当生词本平台为欧路 / 扇贝 / 墨墨时显示）：`不同步（默认）/ 本地生词表 / Zotero 笔记`。启用后，添加生词时除写入所选云端平台外，**同时添加至本地生词表 / Zotero 笔记**。

**「+生词本」按钮设置**（位于「词形选择」/「同步至本地」下方）：

**按钮显示场景**：控制翻译弹窗中 `+`（生词本）按钮的显示条件：
| 选项 | 说明 |
| --- | --- |
| 悬停 + 划词都显示 | 悬停翻译弹窗（圆形 `+`）和划词按钮（`+生词本`）中都显示 |
| 仅悬停翻译显示 | 仅在悬停翻译弹窗中显示（圆形 `+`） |
| 仅划词翻译显示 | 仅在划词翻译按钮中显示（`+生词本`） |

**按钮显示位置**：控制翻译弹窗内圆形 `+` 按钮相对译文核心区的位置——`弹窗左侧` 或 `弹窗右侧`（默认右侧）。

**加词方式**：`手动点击按钮加入生词本` 或 `翻译后自动加入生词本`。

**加词快捷键**：设置全局快捷键，翻译弹窗出现时直接按快捷键即可加入当前单词（等效点击 `+` 按钮）。点击输入框后直接按下键盘按键即自动录制（支持单键或 `Ctrl` / `Alt` / `Shift` / `Meta` 组合），`Backspace` 清空（= 不启用），`Escape` 取消。留空则不启用快捷键。**与发音快捷键互斥**：两快捷键不能设置为相同按键组合（任一方重复时提醒并拒绝保存）。

### 术语库设置

**启用术语库**：勾选后术语库功能生效，可在**划词模式**下看到「+术语库」按钮，点击即可加入术语库。

**术语库平台**：`本地术语表` 或 `Zotero 笔记`（参考生词本平台）：
- `本地术语表`：术语保存到本地 CSV（`hover-translate-eudic-terminology.csv`，独立于生词本 CSV），可设置「存储路径」（留空则保存在 Zotero 配置目录）
- `Zotero 笔记`：术语保存为笔记「术语库」（独立标签），无音标，词条含**缩写**（选填，1-2 个单词的短术语通常没有；留空不影响提交）

**添加术语**：划词翻译弹窗中点击「+术语库」弹出**添加术语**对话框——术语预填划词文本、**缩写自动预填**（输入全称后自动提取首字母生成建议，如 `object-oriented programming` → `OOP`，用户可直接修改或清空）、释义预填弹窗译文；保存后写入术语库。单词（单个英文单词）时弹窗同时显示「+生词本」（左）与「+术语库」（右）两个按钮；**短语（多个单词）时只显示「+术语库」**（生词本针对单词）。

### 侧边栏面板设置

**启用右侧信息栏的生词本面板**：勾选后，在主窗口条目面板与 PDF 阅读器的**右侧信息栏**出现本插件面板（含信息栏图标按钮），点击图标即可显示 / 隐藏生词本面板。

> 侧边栏面板仅对本地平台内容作展示，仅当「生词本平台」或「同步至本地」选择 本地生词表 / Zotero 笔记 时，或者启用术语库时 可使用。切换相关设置时启用状态**实时更新**，无需取消勾选或重启 Zotero。

面板功能：
- **顶部工具栏**：`词/语` 内容切换、`当前条目/所有条目` 视图切换、`译` 隐藏释义、音标图标隐藏音标、播放图标隐藏发音按钮、`序` 排序、`A+` 放大字体 / `A-` 缩小字体（9–24px）、`清空`（需二次确认）。
- **内容切换**：按钮显示「词」= 生词本卡片，「语」= 术语库卡片；术语模式（语）按钮高亮。「语」模式下卡片**不显示音标**，音标位置显示**术语缩写**；「当前条目/所有条目」视图与排序对两种模式通用。
- **视图切换**：`当前条目`（默认）仅显示所选条目的生词 / 术语；`所有条目` 显示全部（该模式下按钮高亮）；切换状态跨重启记忆。
- **排序**：`序` 按钮随模式**三态显示**——倒序「倒」（默认，最新添加在前）/ 顺序「正」（收录先后）/ 字母序 A-Z 图标。
- **单词卡片**：第一行为单词（点击可**跳转原文对应位置**并高亮）+ 音标 + **发音播放按钮**（点击朗读单词，语言跟随「单词语言」设置；隐藏音标后播放按钮自动跟在单词后面），第二行为字典释义；卡片右侧有 `✎` 编辑与 `✕` 删除按钮。
- **术语卡片**：第一行为术语 + 缩写（选填），第二行为释义；编辑 / 删除 / 清空同步写入术语库（本地 CSV 或「术语库」笔记）。
- **同步编辑 / 删除**：面板中编辑 / 删除 / 清空单词会同步写入本地 CSV 或 Zotero 笔记；若「加入生词本时同步添加到注释」已开启且该单词有匹配注释，注释中的单词与翻译也会**同步更新 / 删除**（词形还原感知匹配，`gaps` ↔ `gap` 也能识别）。

### 注释设置

**加入生词本时同步添加到注释**：勾选后，将单词加入生词本时同步在 PDF 上创建 Zotero 注释。支持悬停翻译（hover）和选区弹窗（selection）两种场景。下方注释相关设置（自动翻译 / 保存位置 / 标注方式 / 颜色 / 标签 / 隐藏便签等）**始终显示可操作**，不随勾选状态置灰：

**加入术语库时同步添加到注释**：勾选后，将术语加入术语库时同步在 PDF 上创建 Zotero 注释。

**自动翻译注释**：勾选后，自动将翻译结果写入注释。翻译保存位置通过下拉菜单选择：

| 选项 | 说明 |
| --- | --- |
| 保存翻译至注释评论 | 翻译写入注释的评论字段；原文单词是否同时写入评论由下方「单词保存位置」控制 |
| 保存翻译至注释正文 | 翻译写入注释正文，并可通过下方「翻译保存位置」选择置于单词前或单词后 |

**单词保存位置**：仅在「保存翻译至注释评论」时生效，控制原文单词是否同时写入注释评论：
| 选项 | 说明 |
| --- | --- |
| 不保存至注释评论（默认） | 翻译写入评论，注释正文保留原单词 |
| 保存至注释评论 | 原文与翻译一并写入注释评论 |

**翻译保存位置**：仅在「保存翻译至注释正文」时生效，通过下拉菜单选择翻译与原文的顺序：

| 选项 | 说明 |
| --- | --- |
| 翻译置于注释正文前 | 注释正文格式：`翻译` + `分隔符` + `单词` |
| 翻译置于注释正文后 | 注释正文格式：`单词` + `分隔符` + `翻译` |

**分隔方式**：通过下拉菜单选择原文与翻译之间的分隔方式：
| 选项 | 说明 |
| --- | --- |
| 换行符（默认） | 使用 `\n` 换行分隔 |
| 自定义分隔符 | 使用下方输入框中的自定义字符串分隔 |

**分隔符**：自定义分隔字符串（默认为两个换行符 `\n\n`），仅在「分隔方式」选择「自定义分隔符」时生效。

**标注方式**：选择注释的标注形式——`高亮文本` 或 `下划线文本`。

**标注颜色**：通过颜色选择器拾取或直接填写十六进制颜色值（格式 `#ffd400`）。

**翻译后自动为注释添加标签**：勾选后，为注释自动添加标签，标签名称可在后方输入框设置（默认 `单词`）。标签以**覆盖式**方式设置——插件创建的注释标签始终仅为该标签名，不受其他插件（如 Actions and Tags for Zotero、zotero-style 的颜色标签联动）自动附加标签的影响。

**隐藏 高亮/下划线文本 便签图标**：勾选后，隐藏 PDF 阅读器中高亮 / 下划线 / 图片注释的便签图标（CommentIcon）：
- **隐藏范围**：
  - `仅隐藏单词和术语的便签`：仅隐藏**本插件创建**的注释便签（按注释 ID 精确识别，自动记录于 `annotationTrackedIDs`；不受标注颜色、文本、标签影响，无启发式误判）
  - `仅隐藏全部文本的便签`：隐藏所有高亮 / 下划线 / 图片注释的便签图标
- **独立便签图标**：独立控制独立便签（note）注释图标的隐藏，**不受隐藏范围限制**——选择「隐藏」则隐藏，选择「不隐藏」则显示。
- 注释删除 / 移入回收站时自动清理 ID 跟踪列表；打开 PDF 时自动对照当前注释集合清理残留，无需人工维护。

### 导出设置

**导出内容**：选择导出对象——`生词本`（默认，导出当前生词本平台）或 `术语库`（导出当前术语库平台）。
**导出格式**：支持 CSV / TSV / TXT / JSON 四种格式：
- `CSV`（逗号分隔，Excel 可用）
- `TSV`（制表符分隔，Anki 可用）
- `TXT`（纯文本）
- `JSON`（完整数据结构）
**导出路径**：自定义导出文件保存位置，可点击右侧「选择目录」按钮通过文件资源管理器选择目录路径（v0.2.8 新增）。
**自动定位文件**：勾选后导出完成自动打开文件管理器定位到导出文件（位于「导出内容」选项上方）。
**导出说明**：
- 若导出文件内容有问题，可尝试再导出一次。
- 墨墨背单词和扇贝单词只能导出单词列表，不含音标/释义，因此导出文件只包含单词列。
- 欧路词典、本地生词本与 Zotero 笔记导出包含音标 / 释义完整信息。
- 术语库导出（本地术语表 / Zotero 笔记）包含术语 / 缩写 / 释义信息。

插件 `update_url` 指向 GitHub Releases：

```
https://github.com/SHANGKAIJIE/zotero-hover-translate-eudic/releases/download/release/update.json
```

发布时需在 Releases 中创建名为 `release` 的标签，并附带 `update.json` 与最新的 `.xpi`，Zotero 即可自动检测更新。
